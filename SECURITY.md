# Security and privacy reports

AdhocDraw's main promise is that your diagrams stay on your device. If you find
anything that contradicts that (a network request to another site, a cookie, data
stored or sent that the [privacy notice](PRIVACY.md) does not mention, or a
vulnerability), please tell us.

- Open an issue on this repository labelled "privacy" or "security".
- Please do not publish exploit details or paste private diagrams or personal data into
  an issue. If you need to share details, say so in the issue and we will arrange a way.

What we do: confirm the problem, fix it as soon as practical, and publish a short note
describing what happened and what changed.

Supported version: the live site (www.adhocdraw.com) is always the latest release.
